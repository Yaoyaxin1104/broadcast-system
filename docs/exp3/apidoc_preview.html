广软广播站点歌与投稿系统 · 接口文档

技术栈：Spring Boot 2.7 + MyBatis-Plus + MySQL 8.0  |  版本：v1.0
Base URL：http://localhost:8089/api
用户模块点歌模块投稿模块音频模块留言模块节目单模块

一、通用约定

  • 接口 URL 采用“/api/模块/动作”约定，/api 为应用上下文路径；以 HTTP 方法区分操作：POST 新增/登录、GET 查询、PUT 修改/审核、DELETE 删除。
  • 除文件上传外，请求体与响应体均为 application/json；文件上传使用 multipart/form-data。
  • 所有接口统一返回 Result 结构：{ "code": 状态码, "msg": 提示信息, "data": 业务数据 }。

二、鉴权说明

  • 系统基于 HttpSession 维护登录状态：登录成功后用户对象写入 Session，浏览器通过 JSESSIONID Cookie 保持会话。
  • 需要身份的接口从 Session 读取用户（部分接口通过 userId 参数结合角色校验）；未登录返回“未登录”，角色不符返回“无权限”。
  • 用户密码经 MD5 摘要后存储，数据库中不保存明文密码。

三、统一错误码

错误码含义触发场景
200操作成功请求正常处理完成
400请求参数有误缺少必填参数或参数格式不合法
401未登录或登录已过期Session 中无登录信息或登录状态失效
403没有操作权限角色不符，或调用了非本角色可用的接口
404请求的资源不存在访问了不存在的资源 ID 或文件
409数据冲突用户名已存在等重复数据场景
500系统内部错误服务端未预期的异常
1001业务处理失败业务流程未满足预期，如审核状态不合法

用户模块

POST/user/register鉴权：否
用户注册，密码经 MD5 加密后存储
请求参数
位置参数类型必填说明
bodyusernameString是登录账号，唯一
bodypasswordString是登录密码
bodyroleString是角色：student/staff/teacher
bodyrealNameString否真实姓名
bodystudentIdString否学号
bodyphoneString否联系电话
bodyemailString否邮箱
请求示例
{
  "username": "student1",
  "password": "123456",
  "realName": "张一",
  "studentId": "2024001",
  "role": "student",
  "phone": "13800000001",
  "email": "student1@example.com"
}
响应示例
{
  "code": 200,
  "msg": "注册成功",
  "data": null
}
POST/user/login鉴权：否
用户登录，校验通过后用户信息写入 HttpSession，响应头返回 JSESSIONID Cookie
请求参数
位置参数类型必填说明
bodyusernameString是登录账号
bodypasswordString是登录密码
请求示例
{
  "username": "student1",
  "password": "123456"
}
响应示例
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": 1,
    "username": "student1",
    "realName": "张一",
    "role": "student",
    "status": 1
  }
}
GET/user/info鉴权：是
获取当前登录用户信息，从 Session 读取
响应示例
{
  "code": 200,
  "msg": "success",
  "data": { "id": 1, "username": "student1", "role": "student" }
}
POST/user/logout鉴权：是
退出登录，清除 Session 中的用户信息
响应示例
{
  "code": 200,
  "msg": "退出成功",
  "data": null
}
